### Cách đọc dữ liệu đã sử dụng

```python
import pandas as pd

DATA_DIR = "../data/raw/fma_metadata/"

tracks = pd.read_csv(
    DATA_DIR + "tracks.csv",
    index_col=0,
    header=[0, 1]
)

features = pd.read_csv(
    DATA_DIR + "features.csv",
    index_col=0,
    header=[0, 1, 2]
)

echonest = pd.read_csv(
    DATA_DIR + "echonest.csv",
    index_col=0,
    header=[0, 1, 2]
)

genres = pd.read_csv(DATA_DIR + "genres.csv")
```

**Lưu ý:** Các bảng dùng MultiIndex columns khác nhau. Không đọc chúng bằng `header=0` thông thường.
